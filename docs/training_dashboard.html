🎯 行为克隆 (Behavior Cloning)

特点：最快上手，适合快速验证训练管道。通过模仿专家演示学习策略。

💡 优势： 训练快速、数据高效、实现简单
⚠️ 限制： 泛化性较差、只能做训练过的动作

步骤 1：收集专家数据

使用规则策略生成专家演示数据。

Reach 任务（5-10 分钟）

python examples/collect_expert_data.py --episodes 500 --env reach --output data/expert_reach.npz

Pick-Place 任务（15-20 分钟）

python examples/collect_expert_data.py --episodes 1000 --env pickplace --domain-random --output data/expert_pickplace.npz

步骤 2：训练 BC 模型

Reach BC 训练（10-15 分钟）

python examples/train_bc.py --train --data data/expert_reach.npz --epochs 100 --batch-size 64 --lr 0.001 --log-dir logs/bc_reach

Pick-Place BC 训练（20-30 分钟）

python examples/train_bc.py --train --data data/expert_pickplace.npz --epochs 150 --batch-size 128 --lr 0.0005 --log-dir logs/bc_pickplace

步骤 3：评估 BC 模型

评估 Reach BC

python examples/train_bc.py --eval --checkpoint logs/bc_reach/best_model.pth --env reach --episodes 50

评估 Pick-Place BC

python examples/train_bc.py --eval --checkpoint logs/bc_pickplace/best_model.pth --env pickplace --episodes 50
✅ 预期结果：
Reach 成功率：80-90%
Pick-Place 成功率：60-75%

🚀 PPO 强化学习 (Proximal Policy Optimization)

特点：无需专家数据，自主探索学习，推荐用于主力训练。

💡 优势： 无需标注数据、泛化性强、成熟稳定
⚠️ 注意： 训练时间较长

步骤 1：快速验证（10 分钟）

快速验证训练管道是否正常工作。

python examples/train_ppo.py --train --env reach --timesteps 200000 --n-envs 8 --log-dir logs/ppo_reach_quick

步骤 2：标准训练（30-60 分钟）

Reach 任务标准训练，获得较好性能。

python examples/train_ppo.py --train --env reach --timesteps 1000000 --n-envs 4 --save-freq 50000 --eval-freq 10000 --log-dir logs/ppo_reach
📊 实时监控： 在新终端运行
tensorboard --logdir logs/ppo_reach
然后打开浏览器访问 http://localhost:6006

步骤 3：完整训练（3-5 小时，过夜运行）

Pick-Place 任务完整训练，带域随机化，获得最佳泛化性能。

nohup python examples/train_ppo.py --train --env pickplace --timesteps 5000000 --n-envs 8 --domain-random --save-freq 100000 --eval-freq 50000 --log-dir logs/ppo_pickplace > logs/training_pickplace.log 2>&1 &

查看训练进度：

tail -f logs/training_pickplace.log

步骤 4：评估 PPO 模型

评估 Reach PPO

python examples/train_ppo.py --eval --checkpoint logs/ppo_reach/best_model.zip --env reach --episodes 100

评估 Pick-Place PPO

python examples/train_ppo.py --eval --checkpoint logs/ppo_pickplace/best_model.zip --env pickplace --episodes 100
✅ 预期结果：
Reach 成功率：95%+
Pick-Place 成功率：85-95%

❓ 常见问题

Q1: 训练过程中断了怎么办？

答：PPO 会自动保存检查点，使用 --checkpoint 参数恢复训练：

python examples/train_ppo.py --train --checkpoint logs/ppo_reach/checkpoints/ppo_model_500000_steps.zip --timesteps 1000000

Q2: 训练速度太慢怎么办？

答：增加并行环境数或减少评估频率：

python examples/train_ppo.py --train --n-envs 8 --eval-freq 50000

Q3: 奖励不收敛怎么办？

答：可能需要调整超参数（学习率、批次大小等）：

python examples/train_ppo.py --train --lr 0.0001 --n-steps 4096 --batch-size 128

Q4: 内存不足怎么办？

答：减少并行环境数：

python examples/train_ppo.py --train --n-envs 2

Q5: 如何选择训练方案？

  • 快速验证：BC（1 小时内见效）
  • 日常使用：PPO Reach（1 小时，性能好）
  • 生产部署：PPO Pick-Place + Domain Randomization（过夜训练，最强泛化）

Q6: 训练好的模型如何部署？

答：加载模型并在环境中运行：

from stable_baselines3 import PPO model = PPO.load("logs/ppo_pickplace/best_model.zip") obs, _ = env.reset() for _ in range(1000): action, _ = model.predict(obs, deterministic=True) obs, reward, done, truncated, info = env.step(action) if done or truncated: break

Q7: 如何提高泛化性？

答：启用域随机化（Domain Randomization）：

python examples/train_ppo.py --train --env pickplace --domain-random

这会随机化物体位置、尺寸、摩擦力等参数，提高模型对环境变化的适应性。

Q8: 如何使用 GPU 加速训练？

答：指定 --device cuda 参数（需要 NVIDIA GPU）：

python examples/train_ppo.py --train --device cuda

如果使用 Mac M1/M2，可以指定 --device mps
