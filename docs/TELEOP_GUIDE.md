# 双臂机器人遥控演示收集指南

## 快速启动

```bash
./START_TELEOP.sh
```

或直接运行：

```bash
python tools/teleop_simple.py
```

## 控制方式

**命令行交互版本**（适用于macOS等系统）：
- 每步输入控制指令
- 可以组合多个字母，如 `ws` 表示同时按w和s
- 按回车执行当前指令并步进一步

## 键位说明

### 左臂控制

| 按键 | 功能 |
|------|------|
| W/S | 关节0± (base旋转) |
| A/D | 关节1± (shoulder前后) |
| Q/E | 关节2± (elbow上下) |
| Z/X | 夹爪 开/关 |

### 右臂控制

| 按键 | 功能 |
|------|------|
| I/K | 关节0± (base旋转) |
| J/L | 关节1± (shoulder前后) |
| U/O | 关节2± (elbow上下) |
| N/M | 夹爪 开/关 |

### 录制控制

| 命令 | 功能 |
|------|------|
| r | 开始/停止录制 |
| reset | 重置环境 |
| quit 或 q | 退出并保存 |
| 空格/回车 | 无操作步进 |

## 使用流程

### 1. 启动工具

```bash
./START_TELEOP.sh
```

终端会显示当前状态：
- 物体位置
- TCP位置
- 录制状态
- 夹爪状态

### 2. 熟悉控制

先**不录制**，试试控制：

```
命令 > w          # 左臂关节0正向移动
命令 > s          # 左臂关节0反向移动
命令 > wa         # 同时控制关节0和关节1
命令 > x          # 关闭左夹爪
命令 > z          # 打开左夹爪
```

按回车键后，机器人会执行指令并显示反馈：
- 距离信息（L_dist, R_dist）
- 奖励值
- 录制状态

### 3. 开始录制

当你准备好后：

```
命令 > r          # 开始录制（显示 🔴）
```

从现在开始，所有的观测、动作、奖励都会被记录。

### 4. 执行任务

典型的抓取-放置流程：

```
# 1. 移动到物体上方
命令 > www        # 多次前进靠近
命令 > qq         # 降低高度

# 2. 对准物体
命令 > aa         # 微调位置
命令 >            # 空步等待稳定

# 3. 抓取
命令 > x          # 关闭夹爪

# 4. 提升
命令 > eee        # 抬高

# 5. 移动到目标
命令 > sss        # 向目标移动

# 6. 放置
命令 > qq         # 降低
命令 > z          # 打开夹爪
```

### 5. 停止录制

完成一次演示后：

```
命令 > r          # 停止录制（显示 ⚪）
```

工具会显示保存的轨迹信息：
- 轨迹长度
- 总回报
- 已保存轨迹数

### 6. 重置环境

开始下一次演示：

```
命令 > reset      # 重置，物体和机器人回到初始位置
```

### 7. 退出保存

收集完演示后：

```
命令 > quit       # 退出并保存所有轨迹
```

## 建议策略

### 初学者：单臂简化任务

先只控制左臂完成一个物体：

1. **启动后立即输入 `r`** 开始录制
2. **只用 WASDQE + ZX** 控制左臂
3. **完全忽略右臂**，让它保持静止
4. **目标：把左边的红色物体抓起来放到目标箱**

这样可以快速获得有效演示。

### 进阶：双臂并行

熟悉后尝试双臂同时控制：

```
命令 > wi         # 左右臂同时旋转
命令 > ad jl      # 左右肩部对称移动
命令 > xm         # 双夹爪关闭
```

### 技巧

1. **小步慢移**：一次输入2-3个字母即可，避免过大动作
2. **观察反馈**：每步后查看距离信息，判断是否靠近目标
3. **稳定抓取**：距离<0.1时再关闭夹爪
4. **不求完美**：即使没成功，只要接近目标的演示也有价值
5. **多录几次**：建议至少10-20条演示，增加数据多样性

## 数据格式

录制的演示保存在：

```
demonstrations/dual_arm_teleop/teleop_demos_YYYYMMDD_HHMMSS.pkl
```

每条轨迹包含：

```python
{
    'observations': np.array,  # (T, 28) - 关节+TCP+物体+抓取状态
    'actions': np.array,       # (T, 16) - 关节delta+夹爪
    'rewards': np.array,       # (T,) - 每步奖励
    'episode_length': int,     # 轨迹长度
    'success': bool           # 是否成功

```

## 常见问题

### Q: 机器人不动？

A: 确认输入的命令包含控制字母（wasdqe或ijkluo），空格/回车是无操作。

### Q: 距离不减小？

A: 检查控制方向是否正确，尝试相反方向（如用s代替w）。

### Q: 夹爪没反应？

A: 夹爪状态会保持，再次按x确保关闭，按z确保打开。

### Q: 要录多少条演示？

A: 建议：
- 最少10条（快速测试BC）
- 推荐20-50条（稳定训练）
- 理想100+条（高性能）

即使部分失败也保存，增加数据多样性。
