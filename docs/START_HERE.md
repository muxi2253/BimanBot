# 演示收集快速开始 🎮

选项B已完成！三种演示收集方式可选。

## 快速启动

```bash
./START_TELEOP.sh
```

然后选择：
- **1** - 🖱️ 鼠标拖拽（最推荐，需要GUI）
- **2** - 📊 ASCII可视化（推荐，无GUI环境）  
- **3** - ⌨️ 键盘控制（基础版）

## 三种方案对比

| 方案 | 优点 | 适用场景 |
|------|------|---------|
| 鼠标拖拽 | 最直观，完全可视化 | 有GUI访问，想快速采集 |
| ASCII可视化 | 实时俯视图+距离提示 | **无GUI环境（推荐您用这个！）** |
| 键盘控制 | 最简单 | 熟悉坐标系，快速调试 |

## 推荐：ASCII可视化方案

因为您提到"看不到画面"，推荐使用**方案2：ASCII可视化**。

### 界面示例

```
====================================================
   俯视图 (X-Y平面)  近 ↑ 远
====================================================
│+                                               + │  ← TCP
│  ●                                          ◆    │  ← 物体
│       ░░░░░                                      │  ← 目标箱
====================================================

高度(Z轴):
  左臂: 1.80m  左物体: 0.15m  ← 左臂太高，需要下降！

距离:
  左臂→左物体: 1.663m          ← 还很远
  右臂→右物体: 1.657m 
```

### 快速示例

```bash
./START_TELEOP.sh  # 选择 2

# 熟悉控制（不录制）
命令 > w           # 前进，观察俯视图变化
命令 > q           # 下降，观察高度变化

# 开始录制
命令 > r           # 🔴 开始

# 移动到物体
命令 > www         # 多次前进
命令 > qqqqq       # 多次下降
# 观察距离信息，当出现 "✓ 可抓取" 时：
命令 > x           # 关闭夹爪

# 提升
命令 > eeee

# 移到目标
命令 > ssss
命令 > qq

# 放置
命令 > z           # 打开夹爪

# 停止录制
命令 > r           # ⚪ 停止

# 继续下一次
命令 > reset
```
